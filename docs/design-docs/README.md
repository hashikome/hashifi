# Design documents

Detailed extensions of [ARCHITECTURE.md](../../ARCHITECTURE.md): how each part of the
system works now, too detailed or too likely to change for the root document.
[PRODUCT.md](../../PRODUCT.md) says what HashiFi must do and [DESIGN.md](../../DESIGN.md)
how it looks. Settled rationale is in [../engineering-decisions/](../engineering-decisions/README.md);
future work is in [../backlog/](../backlog/README.md).

Each document states its status, describes what is implemented as current behaviour and
labels what is planned. When work completes, its plan's lasting content is folded into the
document it extends.
